# Echo Pads

Free single-file HTML5 memory game. Six glowing hex pads play a growing
melody — watch the sequence, repeat it by ear, survive the rising tempo.
One wrong pad ends the run. Two modes: Classic and Speed Round.

**Play:** https://shuangyueliao.github.io/echo-pads/

- Mouse / touch / keys 1–6, per-mode best scores saved locally
- Playback speeds up as rounds climb (clearly faster past round 10)
- Procedural canvas visuals & WebAudio pentatonic tones, zero assets,
  single HTML file
